# Como Contribuir para os Projetos da ANPD

Ficamos felizes com o seu interesse em contribuir para os projetos públicos da Agência Nacional de Proteção de Dados (ANPD).

---

## Antes de começar

- **Forks de outros órgãos** (`Ro-dou`, `mod-sei-pen`, `mod-wssei`): envie issues e Pull Requests ao repositório original, indicado no README de cada projeto.
- **Vulnerabilidades de segurança:** siga a [Política de Segurança](https://github.com/anpdgovbr/.github/blob/main/SECURITY.md) e não abra uma issue pública.
- **Assuntos sobre proteção de dados ou atuação da ANPD** (denúncias, petições, dúvidas sobre a LGPD): use os [canais oficiais de atendimento](https://www.gov.br/anpd/pt-br/canais_atendimento/fale-conosco). Issues no GitHub tratam apenas do código e da documentação dos repositórios.

---

## Código de Conduta

Todos os participantes devem seguir o [Código de Conduta](https://github.com/anpdgovbr/.github/blob/main/CODE_OF_CONDUCT.md).

---

## Abrindo uma Issue

Abra uma **Issue** no repositório correspondente usando o template adequado:

- **Bug Report:** descreva o problema, os passos para reproduzi-lo, o comportamento esperado e o que de fato aconteceu. Inclua logs ou prints, se possível.
- **Feature Request:** descreva a proposta e o valor que ela agregaria ao projeto.
- **Dúvidas:** se algo não está claro na documentação ou no código, pergunte.

---

## Enviando um Pull Request (PR)

1.  **Faça o fork** do repositório.
2.  **Crie uma branch** com nome descritivo (ex: `feat/novo-metodo` ou `fix/corrige-validacao`).

    ```bash
    git checkout -b nome-da-sua-branch
    ```

3.  **Desenvolva e teste:** adicione ou atualize testes automatizados e garanta que os existentes continuam passando.
4.  **Siga as convenções do projeto:** respeite o linter, o formatador e o padrão de commits definidos no repositório.

    ```bash
    git commit -m "feat: adiciona funcionalidade X"
    ```

5.  **Abra o Pull Request** para a branch indicada no README do projeto e preencha o template.

### Análise do PR

- A equipe da ANPD revisará o PR assim que possível e poderá solicitar ajustes.
- Após a aprovação, o PR será incorporado ao projeto.
